# Internal Comms

Helps write internal communications using consistent, professional formats.

## When to Use

- Writing a project status update for stakeholders
- Drafting a company newsletter or all-hands summary
- Creating a 3P (progress, plans, problems) update
- Writing FAQs for an internal process or policy
- Drafting an announcement for a team or company

## Common Formats

### 3P Update (Progress / Plans / Problems)

```markdown
## [Team/Project Name] -- Week of [Date]

### Progress (What got done)
- [Completed item 1]
- [Completed item 2]

### Plans (What's next)
- [Upcoming item 1] -- Owner: [Name], ETA: [Date]
- [Upcoming item 2]

### Problems (Blockers / Risks)
- [Blocker] -- Impact: [description] -- Needs: [what help is needed]
```

### Project Status Report

```markdown
## Project: [Name]
**Status**: On Track / At Risk / Blocked
**Last Updated**: [Date]
**Owner**: [Name]

### Summary
[2-3 sentence overview of where things stand]

### Key Milestones
| Milestone | Target | Status |
|-----------|--------|--------|
| [Milestone] | [Date] | Done / In Progress / Not Started |

### This Week
- [What was accomplished]

### Next Week
- [What is planned]

### Risks & Dependencies
- [Risk/dependency and mitigation]
```

### Company Newsletter

```markdown
## [Company/Team] Newsletter -- [Month Year]

### Highlights
[2-3 key things worth celebrating or calling out]

### Product & Engineering
[What shipped, what's in progress]

### People & Culture
[New hires, anniversaries, team news]

### Looking Ahead
[What's coming next month]
```

### FAQ Document

```markdown
# FAQ: [Topic]

**Q: [Question]**
A: [Answer]

**Q: [Question]**
A: [Answer]
```

### General Announcement

```markdown
**Subject**: [Clear, specific subject line]

Hi [team/everyone],

[Opening: what you're announcing in one sentence]

[Context: why this is happening / what led to this]

[Details: the important specifics]

[Action required: what people need to do, if anything]

[Timeline: when this takes effect]

[Who to contact with questions]

Thanks,
[Name]
```

## Writing Principles

- **Lead with the most important thing** -- don't bury the headline
- **Be specific** -- "we shipped X" not "we made progress"
- **Use plain language** -- avoid jargon unless the audience uses it
- **Show numbers** -- "40% faster" beats "significantly faster"
- **State owners** -- every action item should have a name attached
- **Keep it scannable** -- use headers, bullets, and bold for key info

## Tone by Audience

| Audience | Tone |
|----------|------|
| Executive / leadership | Direct, concise, outcomes-focused |
| Cross-functional peers | Collaborative, context-rich |
| Your own team | Candid, detailed, action-oriented |
| All-company | Warm, accessible, inspiring |
