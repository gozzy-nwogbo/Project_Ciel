## Allowed Tools (read-only, no approval needed)

### 1. Search Jobs

Search Indeed listings by keyword, location, and country.

```
Tool: search_jobs
search: "AI engineer"
location: "Toronto, ON"
country_code: "CA"
job_type: "fulltime" (optional: fulltime, parttime, contract, internship, temporary)
```

Output: list of job results with titles, companies, and apply links. Always embed apply links in job titles so the user can click through.

### 2. Get Job Details

Retrieve full description for a specific job.

```
Tool: get_job_details
job_id: "<id from search results>"
```

Output: title, company, location, salary, full description, apply link. Keep URLs intact.

### 3. Get Company Data

Retrieve company information, ratings, and salary data from Indeed's knowledge base.

```
Tool: get_company_data
companyName: "Anthropic"
language: "en"
location: { country: "CA", usState: null, usStateCode: null, usCity: null }
knowledgeCategories: { metadata: true, ratings: true, salaries: true }
```

Provide jobTitle when asking about salary to get role-specific compensation data.

### 4. Get Resume

Retrieve user's Indeed resume data. Useful for context before job searching.

```
Tool: get_resume
(no parameters)
```

## Graceful Degradation

If Indeed MCP server is unreachable:
1. Log to `00-inbox/staging/indeed-unavailable-[date].md` with timestamp and error
2. Surface to user: "Indeed MCP is currently unreachable. Job search unavailable this session."
3. Do not retry silently. Do not fail without notification.
