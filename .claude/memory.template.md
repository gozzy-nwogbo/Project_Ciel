# Memory

Promoted memories from daily logs. Updated by session hooks.

This file accumulates durable operational facts surfaced from session work: convention decisions, architectural commitments, schema changes, and any state that should outlast a single session but doesn't belong in `02-knowledge/`.

## Entry format

- **[Title or commit moment]** ([date]). [One to three sentences. Decision, scope, and why it matters next time.]

## Pruning policy

Reassess when file exceeds ~50 entries or any individual entry passes 60 days unreferenced.
